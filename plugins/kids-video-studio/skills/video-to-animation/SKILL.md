# 视频转动画：动作词和会动的物件

前置：`h5-3d-skin`（物件已有 3D 静态图，`assets/skin/`）；本机 `127.0.0.1:8188` 有 MiniMax H3 服务（`comfyui-h3-cloud` 插件）。
路径相对项目根目录。

## 什么时候需要动画

静态图上 4-6 岁的孩子分不清“跑”和“跳”、“开”和“关”、“推”和“拉”。规则：**动词、动作、会动的天气一律做成动画**。
`python tools/asset_check.py episode episodes/<ep>` 会把没有动画的动作词标出来（词表在脚本的 `ACTION_WORDS`）。
先用 `python tools/asset_check.py find <词>` 查库里是否已有，能复用就复用。

## 做法

在 `assets/skin/prompts.json` 的 `items` 里加一条带 `video` 的物件，然后：

```bash
python tools/make_anim.py <名字>            # 首帧 → H3 图生视频 → 逐帧抠图 → 精灵表 <名字>_anim.png
python tools/make_skin.py --offline         # 刷新 manifest.json
```

1. 已有的物件图贴到纯色幕布上作为**首帧**（`from` 指定物件，`place` 是位置 `[中心 x, 底 y, 高]`，占画面比例）。
2. 提示词只写原地的动作，并写明镜头不动、背景不变、没有地面和阴影。
3. 逐帧色键抠图，按整段里主体碰到的范围裁一个固定方窗（保留位移），打包成精灵表。
4. 引擎按时间取帧（每帧仍是时间的纯函数，逐帧录制可复现）。`anim_<名字>_check.jpg` 是抽帧条，每次都看。

## 先决定：循环还是只播一遍

| 动作 | 形式 | 首尾帧 | 示例 |
|---|---|---|---|
| 持续的动作：跳、跑、拍手、游泳 | 循环 | **首帧 = 尾帧**（默认） | `rabbit_hop` |
| 持续的天气：太阳光芒、云、雨、风 | 循环 | 首帧 = 尾帧 | `sunny` `rainy` `windy` |
| 有结果的动作：打开 | 只播一遍 `once` | `last: "none"`，让模型自己完成 | `open_box` |
| 反过来的动作：合上 | 只播一遍 | `reverse: "open_box"`，倒放打开 | `close` |
| 位移的动作：推、拉 | 只播一遍 | `last: {"place": [...]}`，尾帧是首帧挪了位置 | `push` `pull` |

- 不给尾帧时，模型会自己加森林背景并让角色跑出画面；首尾相同时背景不漂，首尾相接无缝循环。
- **首尾帧用两张分别生成的图（关着的盒子、开着的盒子）时，模型会在中途把一个盒子变成另一个，大小形状都跳。**
  用 `last: none` 生成打开，合上用它倒放，保证从头到尾是同一个盒子。
- 只播一遍的动画：物件出现时开始播，播完停在最后一帧；隐藏后再出现会重播。“准备好”的那一帧（关着的盒子、推之前的姿势）
  另存成静态物件（取动画的第 0 帧），用在题目和故事里，台词说到这个词时再换成动画。

## 选项（`video` 里）

| 选项 | 用途 |
|---|---|
| `frames` | 39 或 56（模型要求 17k+5）。快动作和只播一遍 39，跳、拍手、天气 56 |
| `step` / `fps` | 用全部帧 `step: 1`，循环 14-16fps，只播一遍 18fps。隔帧再慢放会又快又闪 |
| `zoom` / `shift` | 把主体放大到和静态物件差不多；`shift: [x, y]` 像素微调位置（盒子动画和静态盒子对齐） |
| `key` / `keySat` | 幕布颜色 `blue` / `green` 和抠图饱和度阈值 |
| `once` | 只播一遍，停在最后一帧 |
| `last` | `"none"` 只给首帧；`{"place": [...]}` 尾帧挪位置 |
| `reverse` | 倒放另一个物件的视频 |
| `parts` | 保留所有分开的小块（雨点、光芒、落叶、绳子），默认只留最大的一块 |
| `fadeBottom` | 掉出画面的东西（雨点）在底部渐隐，而不是被一条线切掉，取 0.3 左右 |
| `still` | 静态图取哪一帧，`-1` 是最后一帧 |
| `cell` | 精灵表每格像素，280 够用 |

## 幕布颜色和抠图

- 默认蓝幕。**浅蓝的东西和带蓝灰阴影的白云用绿幕**；白色和反光物体两种都要试。
- 物件里本来就有幕布颜色的部分会被一起抠掉：绿叶子在绿幕上变成黑缺口。**改物件的颜色**（风里的叶子改成橙色），不要硬调阈值。
- 抠图会自动去掉物件内部被幕布色填满的洞，并给边缘去色溢。
- 主体是分开的几块（雨点和云、风里的叶子、角色和他拉的绳子）时一定加 `parts`，否则只剩最大的一块。
  绳子太细会被当成噪点去掉：首帧里把绳子画粗。
- 检查：把帧贴在深紫色这类对比色上看，幕布残留和被吃掉的边一眼就能看出来。白云和风的背景要干净，不能多抠出东西。

## 内容经验

- “拍手”不要用一双孤立的手：模型会让一只手转走消失。换成一个角色在拍手。
- “推”“拉”用一个角色推小车、拉绳子，方向要和词一致（推：车在角色前面往前走；拉：角色面朝车往回拽）。
- 天气：太阳光芒慢慢转、云朵轻轻浮动、雨一直下、风卷着叶子从一边吹到另一边。
- 引擎里所有带动画的物件都要走带动画的绘制路径（示例引擎的 `putItem`），新段落类型里直接摆图片是不会动的。
- 封面和缩略图用动画的一帧静态图（`assets/skin/<名字>.png`）。
- 做完逐集重录、看 `python tools/overview_sheet.py episodes/<ep>`，确认动画在说到那个词时正在播。
